# 矩阵的迹与行列式：线性变换的固有不变量与几何体积

当我们用矩阵 $A$ 来描述一个线性变换时，矩阵中的具体数值实际上严重依赖于我们所选取的**坐标基底**（Coordinate Basis）。如果我们将观察坐标轴旋转或倾斜，同一个线性变换所对应的矩阵数字会面目全非。

然而，在线性代数中有两个极其非凡的数值——**迹（Trace）** 与 **行列式（Determinant）**。无论你选择多么奇异的坐标系，它们的值都**恒定不变**。它们是线性变换与生俱来的“固有几何指纹”：

- **行列式 $\det(A)$**：是**乘法不变量**，刻画了空间体积在变换前后的**静态倍率缩放**与定向（Orientation）；
- **迹 $\operatorname{tr}(A)$**：是**加法不变量**，刻画了空间微元在连续流动演化中的**一阶瞬时体积膨胀率**（Jacobi 膨胀率）。

---

## 一、代数定义与核心性质

### 1.1 矩阵的迹（Trace）

对于 $n \times n$ 方阵 $A = (a_{ij})$，其 **迹（Trace）** 定义为主对角线所有元素之和：

$$
\operatorname{tr}(A) = \sum_{i=1}^n a_{ii} = a_{11} + a_{22} + \dots + a_{nn}
$$

**核心代数性质**：

1. **线性性质（加法不变量）**：
   $$
   \operatorname{tr}(A + B) = \operatorname{tr}(A) + \operatorname{tr}(B), \qquad \operatorname{tr}(c A) = c \operatorname{tr}(A)
   $$
2. **转置不变性**：$\operatorname{tr}(A^\top) = \operatorname{tr}(A)$。
3. **循环置换性质（Cyclic Permutation）**：
   $$
   \operatorname{tr}(AB) = \operatorname{tr}(BA)
   $$
   更一般地，对于多个矩阵的连乘，其迹在循环置换下保持不变：
   $$
   \operatorname{tr}(ABC) = \operatorname{tr}(BCA) = \operatorname{tr}(CAB)
   $$
   > **注意**：非循环置换一般不成立（例如 $\operatorname{tr}(ABC) \neq \operatorname{tr}(BAC)$）。

### 1.2 行列式（Determinant）

对于方阵 $A$，**行列式 $\det(A)$** 是唯一的具有多重线性、交错性且满足 $\det(I) = 1$ 的标量函数：

- 二维平面情形：$\det \begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$。

**核心代数性质**：

1. **乘法定理（乘法不变量）**：
   $$
   \det(AB) = \det(A)\det(B)
   $$
2. **可逆性判据**：$A$ 可逆（非退化）当且仅当 $\det(A) \neq 0$；此时 $\det(A^{-1}) = \frac{1}{\det(A)}$。
3. **标量缩放**：$\det(c A) = c^n \det(A)$（对 $n$ 维方阵）。

## 二、相似不变性：与坐标基无关的几何本质

设 $P$ 为任意可逆变换矩阵（代表坐标基变换），则线性变换 $A$ 在新基底下的矩阵表示为 $A' = P^{-1}AP$（称为相似变换，[详见《基、坐标与基变换》](/posts/linear-algebra/basis-coordinate-change-of-basis)）。

利用循环置换性质与乘法定理，我们可以直接证明迹与行列式的**相似不变性**：

### 2.1 迹的相似不变性

$$
\operatorname{tr}(A') = \operatorname{tr}(P^{-1}AP) = \operatorname{tr}\big((P^{-1}A) P\big) = \operatorname{tr}\big(P (P^{-1}A)\big) = \operatorname{tr}(I A) = \operatorname{tr}(A)
$$

### 2.2 行列式的相似不变性

$$
\det(A') = \det(P^{-1}AP) = \det(P^{-1})\det(A)\det(P) = \frac{1}{\det(P)}\det(A)\det(P) = \det(A)
$$

> **几何洞察**：矩阵中每一个单独的数字 $a_{ij}$ 都只是在特定坐标轴投影下的“表象”，而 $\operatorname{tr}(A)$ 和 $\det(A)$ 才是线性变换本身不依赖于观察坐标系的**几何本质**。

## 三、特征多项式与谱关系

迹与行列式也是矩阵**特征值（Eigenvalues）** 的宏观浓缩。方阵 $A$ 的特征多项式为：

$$
p(\lambda) = \det(\lambda I - A) = \lambda^n - c_1 \lambda^{n-1} + c_2 \lambda^{n-2} - \dots + (-1)^n c_n
$$

由韦达定理（Vieta's formulas）可精确证明：

- 最高阶项之后的首个系数恰为矩阵的**迹**：$c_1 = \operatorname{tr}(A) = \sum_{i=1}^n \lambda_i$；
- 常数项恰为矩阵的**行列式**：$c_n = \det(A) = \prod_{i=1}^n \lambda_i$。

在二维空间中，特征多项式具有极其优美的标准形式：

$$
p(\lambda) = \lambda^2 - \operatorname{tr}(A)\lambda + \det(A) = 0
$$

这揭示了迹与行列式正是统领矩阵全部谱分布的两大基石：**迹是特征值之和，行列式是特征值之积**。

## 四、几何体积与 Jacobi 膨胀率

### 4.1 行列式：静态体积缩放与定向

在几何上，矩阵的列向量 $a_1, a_2, \dots, a_n$ 构成了一个平行多面体：

- **面积/体积绝对值**：$|\det(A)|$ 精确给出了单位超立方体在变换 $A$ 作用后的**体积缩放因子**；
- **符号**：$\operatorname{sgn}(\det(A))$ 决定了空间**定向（Orientation）** 是否保持：
  - $\det(A) > 0$：定向保持（如旋转、等比缩放）；
  - $\det(A) < 0$：定向翻转（如镜面反射、手性翻转）；
  - $\det(A) = 0$：空间降维坍缩（退化为平面、直线或点，不可逆）。

### 4.2 迹：动态连续流动与 Jacobi 膨胀率

如果说行列式度量了离散变换 $A$ 的最终体积比例，那么**迹 $\operatorname{tr}(A)$ 则度量了连续时间流动微元的瞬时膨胀速度**。

考虑沿流场 $\dot{\mathbf x} = A \mathbf x$ 演化的微小线性流动变换 $M(t) = I + t A$。在微小时间步 $t$ 内，几何区域体积的演化为：

$$
\text{Vol}(t) = \det(I + tA) = 1 + t \operatorname{tr}(A) + t^2 \det(A) + \mathcal{O}(t^3)
$$

对其在初始时刻 $t = 0$ 处求时间导数（**Jacobi 公式**）：

$$
\left.\frac{d}{dt} \text{Vol}(t)\right|_{t=0} = \left.\frac{d}{dt} \det(I + tA)\right|_{t=0} = \operatorname{tr}(A)
$$

这给出了迹最深刻的几何与物理意义：

- **$\operatorname{tr}(A) > 0$**：空间微元在初始流动中**体积膨胀发散**（正源）；
- **$\operatorname{tr}(A) < 0$**：空间微元在初始流动中**体积收缩耗散**（负汇）；
- **$\operatorname{tr}(A) = 0$（无迹矩阵）**：空间微元在连续演化中**严格保持体积不变**（如不可压缩流体、纯保体积剪切）。

> **与微积分中散度的深层统一**：
> 在向量场 $\mathbf F$ 中，微元的体积发散率正是其散度 $\operatorname{div}(\mathbf F)$。由微积分可知，$\operatorname{div}(\mathbf F) = \operatorname{tr}(J_{\mathbf F})$——**散度本质上就是向量场 Jacobian 矩阵的迹**！

## 六、矩阵内积与正交投影的“秩等于迹”

迹在线性代数的高阶几何中还扮演着“矩阵空间内积”与“投影算子维度计数”的关键角色：

### 6.1 Frobenius 矩阵内积

将 $m \times n$ 矩阵空间本身视为向量空间，利用迹可以定义标准内积：

$$
\langle A, B \rangle_F = \operatorname{tr}(A^\top B) = \sum_{i=1}^m \sum_{j=1}^n a_{ij} b_{ij}
$$

其诱导的模长即为广泛应用于计算机图形学、物理模拟与深度学习中的 **Frobenius 范数** $\|A\|_F = \sqrt{\operatorname{tr}(A^\top A)}$。

### 6.2 投影矩阵的代数奇迹：$\operatorname{rank}(P) = \operatorname{tr}(P)$

对于任意正交或斜投影算子 $P$（满足幂等性 $P^2 = P$），其所有特征值只能是 $0$ 或 $1$。由迹等于特征值之和的性质：

$$
\operatorname{tr}(P) = \sum_{i=1}^n \lambda_i = 1 \times (\text{特征值 } 1 \text{ 的个数}) + 0 \times (\text{特征值 } 0 \text{ 的个数}) = \operatorname{rank}(P)
$$

投影矩阵的主对角线之和，奇迹般地直接给出了其**投影子空间的维度（秩）**。

## 七、迹与行列式全景对照表

| 核心维度           | 矩阵的迹 $\operatorname{tr}(A)$                                                      | 矩阵的行列式 $\det(A)$                                                  |
| :----------------- | :----------------------------------------------------------------------------------- | :---------------------------------------------------------------------- |
| **代数形式**       | 主对角线元素之和 $\sum a_{ii}$                                                       | 列向量交错多线性形式                                                    |
| **代数运算性质**   | **加法不变量**：$\operatorname{tr}(A+B) = \operatorname{tr}(A)+\operatorname{tr}(B)$ | **乘法不变量**：$\det(AB) = \det(A)\det(B)$                             |
| **相似变换不变性** | $\operatorname{tr}(P^{-1}AP) = \operatorname{tr}(A)$                                 | $\det(P^{-1}AP) = \det(A)$                                              |
| **特征谱联系**     | **特征值之和** $\sum \lambda_i$                                                      | **特征值之积** $\prod \lambda_i$                                        |
| **静态几何意义**   | 向量场 Jacobian 的散度通量                                                           | 单位立方体变换后的体积缩放因子与定向                                    |
| **动态几何意义**   | 连续流动下的**一阶体积膨胀速度**                                                     | 连续时间流下的累积总膨胀倍率 $\det(e^{tA}) = e^{t\operatorname{tr}(A)}$ |
| **微积分桥梁**     | $\operatorname{div}(\mathbf F) = \operatorname{tr}(J_{\mathbf F})$                   | 多元微积分变量替换的 Jacobian 决定因子                                  |
