# 线性组合、线性相关与线性无关

向量空间的几何直觉很好懂：箭头、平面、空间。但要真正“算”起来，一切都要落到 **线性组合(linear combination)** 上；而一组向量究竟是“各自独立”还是“彼此重复”，则由 **线性相关 / 线性无关(linear dependence / independence)** 刻画。这两个概念是理解向量空间、基，以及矩阵的列空间与秩的第一块积木。

## 线性组合

给定 $k$ 个向量 $v_1, v_2, \ldots, v_k$ 和 $k$ 个标量 $c_1, c_2, \ldots, c_k$，表达式

$$
c_1 v_1 + c_2 v_2 + \cdots + c_k v_k
$$

叫做这组向量的一个**线性组合(linear combination)**。标量 $c_i$ 就是每个方向的“用量”。

最简单的例子在 $\mathbb{R}^2$：设 $e_1 = (1,0)$、$e_2 = (0,1)$，那么

$$
3e_1 + 2e_2 = 3(1,0) + 2(0,1) = (3,2)
$$

反过来，任何一个 $(x,y)$ 都可以写成

$$
(x,y) = x e_1 + y e_2
$$

所以“线性组合”就是用一组向量作为原料，按一定用量“搭出”一个新的向量。所有可能的线性组合放在一起，就是这组向量的**张成(span)**:

$$
\operatorname{span}\{v_1, \ldots, v_k\} = \left\{ c_1v_1 + \cdots + c_kv_k : c_1, \ldots, c_k \in \mathbb{R} \right\}
$$

张成就是我们能“搭出来”的全部向量的集合——矩阵的列空间正是列向量的张成（见[《矩阵的秩、列空间与行空间》](/posts/linear-algebra/matrix-rank-column-row-space)）。

## 线性相关

一组向量 $v_1, \ldots, v_k$ 称为**线性相关(linearly dependent)**，如果存在**不全为零**的标量 $c_1, \ldots, c_k$ 使得

$$
\boxed{c_1 v_1 + \cdots + c_k v_k = 0}
$$

“不全为零”是关键词：平凡组合（所有 $c_i = 0$）当然得到零向量，线性相关说的是**存在非平凡的零组合**。

这等价于：其中至少有一个向量可以写成其余向量的线性组合。因为若 $c_1 \ne 0$，移项即得

$$
v_1 = -\frac{c_2}{c_1}v_2 - \cdots - \frac{c_k}{c_1}v_k
$$

几何直觉：**线性相关 = 这组向量里至少有一个是“多余的”，没有带来新的独立方向**。

例子：

- 两个共线向量 $(1,2)$ 与 $(2,4)$：因为 $2(1,2) - (2,4) = 0$，它们线性相关；
- 平面里任意三个向量必线性相关：三个二维向量中最多两个能保持独立，第三个必然能由前两个组合出来。

## 线性无关

反过来，如果**只有全零组合**才能得到零向量，这组向量就称为**线性无关(linearly independent)**:

$$
\boxed{c_1 v_1 + \cdots + c_k v_k = 0 \;\implies\; c_1 = c_2 = \cdots = c_k = 0}
$$

等价地说：每个向量都不能由其余向量线性表示——谁也不是“多余的”。

几何直觉：**线性无关 = 每个向量都带来一个真正的新方向**。

例子：

- $(1,0)$ 与 $(0,1)$ 线性无关：若 $c_1(1,0) + c_2(0,1) = (c_1, c_2) = 0$，只能 $c_1 = c_2 = 0$；
- $(1,1)$ 与 $(1,-1)$ 线性无关：由 $c_1(1,1) + c_2(1,-1) = (c_1+c_2,\; c_1-c_2) = 0$ 解得 $c_1 = c_2 = 0$；
- $(1,0)$ 与 $(2,0)$ 线性相关：它们都在 $x$ 轴上，$2(1,0) - (2,0) = 0$。

## 为什么重要

“无关”与“张成”合在一起，就定义出向量空间的**基(basis)**:

$$
\boxed{\text{basis = a linearly independent set that spans the whole space}}
$$

一组 $n$ 个线性无关的向量张成一个 $n$ 维空间，它们就是给这个空间“命名坐标”的参照系——这正是[《基、坐标表示与基变换》](/posts/linear-algebra/basis-coordinate-change-of-basis)的主题。

同时，“独立方向的个数”正是线性代数里最核心的量之一：**列空间的维数就是列向量中独立方向的个数，也就是秩(rank)**（见[《矩阵的秩、列空间与行空间》](/posts/linear-algebra/matrix-rank-column-row-space)）。

> 线性组合 = 用一组向量按一定用量搭出新向量；线性相关 = 存在非平凡的零组合（有人多余）；线性无关 = 只有全零组合才得零向量（每个人都是新方向）。无关 + 张成 = 基。
