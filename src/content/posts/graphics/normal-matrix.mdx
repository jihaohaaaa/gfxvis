# 法线矩阵 Normal Matrix

顶点位置可以直接用 Model Matrix 变换,但**法线不能**。

## 为什么不能直接变换?

非均匀缩放下,直接用 Model Matrix 变换法线会破坏它与切面的正交性。切向量 $t$ 与法向量 $n$ 满足:

$$
n^T t = 0
$$

变换后,切向量变成 $Mt$,法向量需要变成 $Nn$,仍然要保持正交:

$$
(Nn)^T (Mt) = n^T N^T M t = 0
$$

因此必须有 $N^T M = I$,即:

$$
N = (M^{-1})^T
$$

## 代码

C++ 侧:

```cpp
glm::mat3 normalMatrix =
    glm::transpose(glm::inverse(glm::mat3(model)));
```

GLSL 侧:

```glsl
vec3 normal = normalize(normalMatrix * inNormal);
```
